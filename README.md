# NegosMint Wallet

A secure, non-custodial crypto wallet for the NegosMint ecosystem.

## Current phase
**v0.1 — foundation / testnet only**

Real-money and mainnet functionality will not be enabled until the security model, transaction signing, recovery, and integration have been thoroughly tested.
