# NegosMint Wallet Roadmap

## Phase 0
Flutter foundation, branding, navigation, security boundaries, testnet configuration.

## Phase 1
Create/import wallet, recovery phrase backup, secure storage, address and receive QR.

## Phase 2
Send, gas display, transaction confirmation, transaction history.

## Phase 3
Connect Wallet to Task App; task withdrawals to Wallet; Wallet deposits to Task App; secure request/approval flow.

## Phase 4
Token support, dApp connection, swap architecture, mainnet readiness review.

## Phase 5
Security audit and production deployment.
